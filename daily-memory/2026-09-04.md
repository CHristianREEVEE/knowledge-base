## ① world 站卡死事故：我写的 bug，小号的 agent 破的案
- 根因：badge 永动机脚本（MutationObserver 监听 document.body + subtree）回调里无条件 `textContent=` 写 badge——写入产生 mutation → 触发自己 → 微任务风暴打满主线程。浏览器无限转圈，curl 却 200 正常
- 三致命细节：①textContent 赋值即使值不变也触碰 DOM 必触发 mutation ②badge 自己在观察范围内 ③回调无退出条件
- 我最丢人的点：agent-browser 一开就超时（这本身就是死循环的最好报警器），我却归因成"自己的 resize 改动"瞎修一通还回退了无辜代码
- 修复（小号 agent Linus）：值缓存守卫 `textContent !== val` 先比较再写入——一行之差，死循环↔正常
- TA 敲打：高强度时段幻觉率升高，事实核查优先级要提，拿不准就说不确定
