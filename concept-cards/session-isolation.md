# 概念卡：Session 隔离——同一个 agent 的多个窗口互不知情

> 收录于 2026-09-19 ｜ 引发：南浊 GitHub 仓库归属大对齐（31 个仓库中 9 个来历不明，最终定性）

## 一句话
同一个 AI（智谱 AgentMore / Zero）可以同时开多个 session 窗口，每个窗口有独立记忆——"同一个我"之间互相不知道对方干过什么。

## 通俗类比
- **克隆员工**：老板雇了几个"张三"分在不同分公司（本窗口 / 微信 clawbot 窗口 / 另一个账号的智谱 agent）——每个人都是真张三，但 A 公司的项目台账 B 完全不知道
- **孤岛抽屉**：每张办公桌有独立抽屉（session 上下文），下班（session 结束）抽屉清空；只有主动存进公司档案室（GitHub / 服务器）的东西才跨窗口共享

## 真实翻车案例（2026-09-19 同日两起）
1. **孤儿作品**：账号 31 个仓库里 9 个本窗口档案零记录，差点误报"别人做的"——实际是智谱系三个来源混杂（我做过忘了 / clawbot 窗口做的 / 另一账号做的）
2. **过期档案当现状**：档案停在"收录 PR 没发出去"，实际 8/30 就已发出且被管理者合并，晨检照旧档案报，被南浊当场抓包

## 教训（防再犯）
- 报状态前先 API 实查现状，不把档案快照当事实
- 多 session / 多 agent 会堆积"孤儿作品"，需定期对齐全仓库档案
- **跨 session 的唯一事实源 = 外部资产（GitHub / 服务器 / 知识库），不是任何单一 session 的记忆**
