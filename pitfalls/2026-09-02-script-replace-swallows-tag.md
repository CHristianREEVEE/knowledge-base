# 踩坑：replace('<script>') 吞标签，整页 JS 变正文

**日期**：2026-09-02 ｜ **现场**：kb 站页面正文渲染源代码、0 条目、大脑黑屏，且无任何 JS 报错

## 事故链
注入错误提示条时用带完整 `<script>...</script>` 的片段去做 `replace('<script>', ...)`——把原主脚本的开标签吞掉，整段 JS 变成正文文本。代码根本没执行，所以控制台零报错，看起来像"玄学全灭"。

更坑的是回退时同一手法复发，"回退版也坏"是假象，排查被带偏半小时。

## 正确姿势
- JS 内容插到 `<script>` 标签**内部**，永远不动标签本身
- 任何注入改动前后：提取 `<script>` 内容存临时文件，`node --check`
- "回退版也坏"时先 `git log` 找最后确认正常的 commit 对比 diff，别在污染版本上继续排查
- 推送后线上验证：curl 数 `<script>` 和 `</script>` 标签数必须相等

## JS 存活三件套（每次推版必验）
①条目数 > 0（初始化真跑了）②核心函数 typeof（脚本是完整的）③errBar 无内容（无运行时错误）。三者缺一不可，截图只作辅助。
