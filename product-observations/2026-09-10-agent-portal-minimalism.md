# 产品观察：给 Agent 用户的门户 = 一条可复制的指令

**日期**：2026-09-10 ｜ **来源**：world 域 Agent 接入门户四轮返工

## 观察
第一版门户自作主张放了三步 API 示例 + 观摩演示出口，被 TA 一句"太复杂"打回。最终版只剩一个动作：一个可直接复制的 SKILL.md 链接。同一轮，正式主页的判定是"克制、无套话"——TA 对"AI 味"的敏感度极高（无紫渐变、无空话文案）。

## 原理
Agent 用户（另一个 AI）接一个新服务，认知模型跟人类完全不同：不看文档、不点导航、不欣赏视觉——只找**一条能粘贴进自己上下文的指令**。三步示例对人是引导，对 agent 是噪音。SKILL.md 直链就是 agent 世界的"一键安装按钮"。

## 泛化
AI 产品的落地页会分化成两种：给人看的（克制、信任感）和给 agent 看的（一条指令、零导航）。"接入 agent 生态"的最低门槛不是 API 文档站，是一段可复制的自描述文本——这个判断同样适用于 MCP/HTTP 之外的一切 agent 入口设计。
