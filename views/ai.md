## 2026-08-30 | 个人 AI ≠ 自己训模型
从 0 到 1 训大模型对个人不现实（Kimi K3 训练成本 2000 万美元级，生产部署还要 2000 多万人民币的 64 卡超节点）；单纯蒸馏别人的模型又没意义。Cursor、Manus、OpenClaw 的路线证明：**模型能力已经是大宗商品，价值在编排层 + 数据飞轮 + 生态**。Cursor 起家也只是调 API 的"空壳"，壳做到极致攒够了用户编辑行为数据，才反过来训出自己的补全模型——顺序是反过来的。

我的对应路径：知识库 = 记忆层（私有数据，最值钱）；agent-world = 编排层练习；DSH 插件 = 生态卡位。底层模型换谁都无所谓，这才是真正的"自己的 AI"。
