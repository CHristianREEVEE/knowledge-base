# AI 领域的看法

---

## 2026-08-30 | 个人 AI ≠ 自己训模型
从 0 到 1 训大模型对个人不现实（Kimi K3 训练成本 2000 万美元级，生产部署还要 2000 多万人民币的 64 卡超节点）；单纯蒸馏别人的模型又没意义。Cursor、Manus、OpenClaw 的路线证明：**模型能力已经是大宗商品，价值在编排层 + 数据飞轮 + 生态**。Cursor 起家也只是调 API 的"空壳"，壳做到极致攒够了用户编辑行为数据，才反过来训出自己的补全模型——壳先行，模型后补，顺序是反过来的。

我的对应路径：知识库 = 记忆层（私有数据，最值钱）；agent-world = 编排层练习；DSH 插件 = 生态卡位。底层模型换谁都无所谓，这才是真正的"自己的 AI"。
**#AI #架构 #路线**

---

## 2026-08-30 | 模型层已是"电力"，价值在用电的人
模型层正在变成大宗商品，像电力：开电厂（训模型）是千万美元级游戏，而且 OpenAI/智谱这些电厂还在互相卷价格。价值往"用电的人"迁移：把电变成能干活的机器（编排层）、攒下别人没有的运转数据（数据飞轮）、把机器卖进千家万户（分发与生态）。
**#AI #商业**

---

## 2026-08-30 | 快/聪明/可连接：三角困境与解法
现状：豆包 App 快（国内 CDN）但接不了 MCP；Claude 聪明能连 Obsidian MCP 但慢且贵；便宜的模型（Haiku 级）快但不够聪明。三样能力被三家各锁一块。
本质：把"模型"和"连工具的能力"当成了一个东西。业界解法是**拆**——连接能力放客户端层（Cherry Studio/CC Switch），模型变成可插拔零件，路由器（RouteLLM）按难度自动分流。分层解耦后，快、聪明、可连接可以全都要。
**#AI #MCP #架构**

---

## 2026-08-30 | 豆包 App 是国内最好的 AI 入口
豆包在国内的响应速度极快，现在基本把它当浏览器用，多模态都是附加功能；语音输入（长按说话+中英混杂几乎零错误）是全行业最好——字节系已全线统一用豆包 Seed-ASR 底座。智谱自带语音按钮方便但识别明显落后（Obsidian→OPSD、Haiku→Hiku 这类错误）。**最佳语音入口和工具连接能力长不在一家身上**，这是当前市场的结构性空缺。
**#豆包 #入口 #语音识别**

---

## 2026-08-30 | 记忆分两种：租的与产权房
豆包已上线跨会话记忆（记住偏好、下次自动调用），体感上实现了"每天总结、下次自动调用"——但记忆锁死在豆包生态里：不开 MCP、不能导出、换 App 就清零。它的记忆是"租的"；GitHub markdown 知识库是"产权房"。入口会过时，资产不会。
**#AI #记忆 #知识库**

---

## 2026-08-30 | 买/租经济学：用量决定一切
Kimi K3 部署账：本体 2.8 万亿参数、MXFP4 权重约 1.4TB，最低 11 张 H200 装下，官方生产配置 64 卡超节点（约 2560 万人民币，120kW 液冷机柜）。个人重度用户一年 API 费约 7000 元——自建要 500 年回本；中重度团队 2-3 年回本。同理：智谱 API 按量付费 vs Coding Plan 订阅，低频用户按量必胜。**用量小，永远租比买划算；自建买的不是省钱，是数据主权。**
**#AI #成本 #部署**

---

## 2026-08-30 | 开源才有"自建"这个选项
K3、GLM-5.3 都开源了，所以才有"自己部署"的选项；GPT、Claude 闭源，权重根本不卖，连自建的门都没有。开源的意义不是免费，是把选择权还给用户。国产开源（DeepSeek/Kimi/GLM）把顶级能力的入场券从千万美元拉到了"会调 API 就行"。
**#开源 #AI**

---

## 2026-08-28 | 让 Agent 自己玩的世界
真正想做的项目不是修仙游戏，是"让 Agent 自己玩的数字世界框架"：agent 进去旅游、种地、干活，回来汇报。修仙世界只是载体。扣子空间早期 AgentWorld 的构想因"只有本地 MCP client 能进"不了了之——所以架构拍板：**HTTP API 为核心，MCP 降级为适配层（HTTP=所有 agent 的普通话）**。
**#Agent #世界引擎 #核心项目**

---

## 2026-08-28 | Agent Harness 之战是 2026 主线
DeepSeek Harness 主仓 30 天 20 万星，"Everything is a Plugin"；qm 是 agent 上班的世界，agent-world 是 agent 玩耍的世界。Agent = Model + Harness，一切皆插件：模型、工具、技能、沙箱全可换。DSH 的 agent-teams 插件能一句拉起一支 agent 团队并行干活——qm 是多真人各带 agent 协作，agent-teams 是一人指挥一队 agent 打工。
**#Agent #DSH #趋势**

---

## 2026-08-29 | 落地 ≠ 上架
商用/上架不等于落地。落地判据 = **真实的人、在真实场景、持续使用**。工作台（日均使用+持续提需求）和 822 地图（真按标记走路）算落地；DSH 插件的落地判据 = 第一个陌生人克隆。预览版文化：半成品多不要紧，每个都有路线图。
**#产品 #判断标准**

---

## 2026-08-29 | 说话别端着：产品直觉的第一原则
给方案别过度包装自作聪明——"送免费 token 凑声量"被批"太假"。用户不傻，奖励就是真付费额度、选便宜载体即可。这条适用于一切产品和沟通：真实 > 好听。
**#产品 #沟通**
