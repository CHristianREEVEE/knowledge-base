# knowledge-base

南浊的个人知识库——观点、观察、踩坑，进系统的才算数。

> 收藏 ≠ 知识。发到微信小号/备忘录的东西 = 死存储。
> 这个库的目的：**存得下 + 找得到 + agent 随时能调用**。

## 目录结构

| 路径 | 用途 | 规则 |
|---|---|---|
| `inbox.md` | 快速捕获池 | 所有想法先进这里，每周归档到对应分类 |
| `views/ai.md` | AI 领域的看法 | 每条带日期和标签 |
| `views/learning.md` | 对学习的看法 | 同上 |
| `views/work.md` | 对工作的看法 | 同上 |
| `product-ideas.md` | 产品观察 | 抖音搜索逻辑这类"要是我就这么改" |
| `pitfalls/` | 踩坑本 | 报错记三行：报了什么/为什么/怎么解 |
| `concept-cards/` | 概念卡片 | 通俗类比式（费曼法），一个概念一张卡 |
| `weekly/` | 周复盘 | 宁短勿断 |
| `job-ammo/` | 求职弹药 | 面试复盘+项目一页纸（后续迁私有仓） |
| `docs/` | 静态展示页 | GitHub Pages 从这里发布 |

## 条目格式

```markdown
## YYYY-MM-DD | 标题
正文……
**#标签1 #标签2**
```

## 更新方式

- 日常更新：跟 Zero 说一声，记录入库并同步到展示页
- 路线图：iOS 快捷指令「记灵感」语音直写 inbox.md；GitHub Actions 自动构建页面；文件附件上传
