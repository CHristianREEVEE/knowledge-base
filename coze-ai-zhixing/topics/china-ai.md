# 国内 AI 观察

> 时间跨度：2026 年 7 月初 – 8 月底见闻，2026-08-31 统一归档。原话照录。

## 字节系

- 除了微信和支付宝干不过，其他全领域覆盖。抖音生态护城河像微信的关系链——渗透了中国每个人，直播、电商覆盖也广；飞书干钉钉，豆包干 C 端大模型。后面努努力搞顶尖大模型很简单，毕竟字节有的是钱。扣子等豆包模型搞好直接接最顶尖的模型，C 端订单也就多了
- 豆包当年也是横空出世的天才，只能说 AI 迭代太快了
- 豆包智能体 7.15 下架：当代年轻人对虚拟形象的依赖；国家监管
- 豆包无多选消息创建新对话功能，只支持单条消息对话
- 豆包也能连接外部程序了：GitHub、飞书
**#字节 #豆包 #护城河**

## DeepSeek

- 中美就是互相抄，美国领先中国大概一两个季度，没有一个是真全靠自己不借鉴同行的，无非是借鉴多少和嘴硬不嘴硬。DeepSeek 本来就以性价比著称，不如 Claude 很正常。网上早有人说要是 DeepSeek 能用一半价格达到 fable5 百分之八十的性能就膜拜了
- 现在国内几个半步 fable5 境界的应该是 Kimi K3、GLM5.2 和千问 3.8max
- DeepSeek 之前就是永远用低价格达到同行 80% 水准。fable 和 gpt5.6 现在断层了，DeepSeek 要是还能干啥那真是疯狗——追在所有大模型后面，超过了没奖励，被追上就要被咬一口狠的，跌股票不说，受众少才是硬伤，DeepSeek v4 发布就验证了这一点
- 梁叔叔还有国补，还有自己的幻方量化，没钱了会自己去股市取，还有几个巨头的投资，五年锁定期，无敌了
- DeepSeek 的 UI 算是简洁好用的
**#DeepSeek #性价比 #中美AI**

## 智谱系

- 智谱 agent AgentMore：从随便玩玩到主力
- **AgentMore 太好用了，要是能单独拿出来就好了，然后自己搞一套体制，搞五小时滚动制，无敌**（08-31 下午，积分焦虑中说出——月度积分两三天耗尽，TA 想要的理想形态=AgentMore 的体验 × 自控的计费体制）
- 智谱的 AutoClaw UI 堪比灾难，太乱了，没有章法，多端云机同步一堆 bug；连一键复制消息都不行，但是可以一下传 17 张图
- 智谱清言没有查找聊天记录的入口
- HuggingFace 被 ChatGPT 训练模型攻击的事件，最后是 GLM5.2 擦的屁股
- **GLM-5.3 本地部署行情（08-31 查证）**：本体 743B 量化后 433GB（8×A100 级，个人无缘）；Flash 版 320B 总参/18B 激活是平民解——1bit 动态量化 102GB RAM/VRAM，二手 EPYC+128G+4090D 约 4000-5000 元、10-20 tok/s；Q4 版 256G 平台 6000-8000 元；结论：个人永远 API 优先（Flash 免费档），本地只在隐私/离线需求（如客户图纸不出网）时是生产资料
**#智谱 #AgentMore #AutoClaw #GLM5.3 #本地部署**
