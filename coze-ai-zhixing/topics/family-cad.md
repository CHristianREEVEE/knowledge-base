# 家庭 CAD 出图业务（爸的草图 → 我的成品）

> 2026-08-31 立项。南浊的商业构想+Zero 技术侦察全程归档。

## 商业模式

- 我爸做施工，在纸上笔画草图让别人电脑画简图、代做图画 CAD 图，有的收一张 900
- 我觉得这个我可以搞：爸画草图 → 我出成品，中间商差价自己吃
- 后续拉生意：让他朋友有需求都来找我。笔画草图第一步转电子简图直接给 Zero 都能生成，但 CAD 就需要想办法
- **定价分层**：纯户型简图 100-200 / 标准施工图（平立剖+标注）500-700 / 复杂节点图 800-1200
- 牌：24 小时出图 + 半价 + 错了免费改；第一单免费做样品给爸拿去群里晒

## 技术路线（定稿架构：两层）

- **底稿层（ezdxf，Zero 沙盒已验证）**：草图照片 → GLM-4.5V 视觉识别尺寸/线条 → 坐标表 JSON（爸目检）→ ezdxf 生成 80 分底稿 DXF
  - ezdxf：纯 Python、MIT 协议（商用零成本）、免装 CAD，本沙盒已现场跑通三次迭代
  - 依赖管理：不进仓库本体，requirements.txt 声明 + pip install
- **精修层（AutoCAD 本体 + MCP）**：puran-water/autocad-mcp（474★）接真 AutoCAD，做标注链校准、标准图块替换、图框、客户改图交互
  - 分层理由：凭空生成补不了图块库积累（人家库里几千个专业块）和改图交互（CAD 里 10 秒 vs 重新生成一轮）——最后 20% 质感交给 CAD 本体
- 侦察结论：GitHub 的 AutoCAD MCP（474★/122★/65★）全是给装了 CAD 的工程师用的；"手绘草图→CAD"全链路无现成产品=真空地带
- DWG 转换：ODA File Converter（免费）补最后一道

## 制图语言学习（对标真实样图）

- 看了 3+2 张真实 CAD 户型图后提炼六条：实心填充墙（poché）/家具全布置（床柜沙发桌洁具橱）/外部两道尺寸/白底黑线/十字轴线+入口箭头/房间名+净尺寸
- TA 纠偏记录：①标注要用引线+建筑斜线起止符（国标）②"还是不行，去看真实样图"——v2 工程骨架→v3 对标样图重画
- 链式标注样图（TA 15:16 发）：29200 总长拆 11 段连墙厚都标——下一轮迭代复刻
- v3 已达成：中文渲染成功（wqy 字体 ttc→ttf 拆装）、HATCH SOLID 实心墙、全套家具、两道尺寸

## 出图工位（硬件）

- 一两千 ThinkPad 跑 2D CAD 完全够（AutoCAD 2024 官方门槛：2.5GHz+8G+集显；2D 不吃独显）
- 推荐：T14 Gen1 i5/16G/512G（1400-1900）首选；T480s（1200-1600）；T480+自加内存（性价比王）
- 验机三条：16G 内存 / SSD 256G+ / 1080P 屏；E480/T440p 别碰
- 这台机=autocad-mcp 载体，1500 块≈一张图的价钱搞定全套基建
